The tool has **no runtime dependencies**: no npm packages, no CDN, no build

written from the published specifications in this repository. What follows is
therefore not a list of bundled code but a list of debts.

in them — engraved text uses this project's own single-stroke font, because an
outline font handed to a laser is cut round its edge and the counters of an "8"
drop out.

## Techniques and prior work

- **The proportional-symbol method** used by the circle grid and the halftone
  is Marc Ihle's own technique, first published for Hadseløya in 2017 on
  digital-landscapes.com, generalised here.
- **The DLF laser-pass layer scheme** (`DLF-00_engrave` … `DLF-05_cut_outer`)
  is carried unchanged from **DL-TerrainSlicer** and, before it, from the
  Grasshopper definition it replaced — so an existing Trotec JobControl
  configuration works as it stands.
- **Hachures** follow the convention set out by Johann Georg Lehmann (1799) and
  developed in the Swiss manner: strokes down the fall line, heavier and closer
  where the ground is steeper. The same notation survives in the modern grading
  plan as the ticked embankment.
- **Marching squares by triangle** avoids the saddle ambiguity of the square
  formulation; the approach is standard and long predates this implementation.
- **Sutherland–Hodgman** polygon clipping is used to close region rings against
  the sheet edge.
- **Horn's method** is used for slope, because it is the derivative every GIS
  agrees on.
- The **interface grammar, the committed theme and the stack** come from the
  sibling tool **DL-TerrainDiversity**; the theme is a deliberate byte-identical
  copy of its stylesheet with two documented token overrides.

## Formats

DXF is written as **R12 (AC1009)**, a format Autodesk published openly and
which every laser front-end reads. SVG follows the W3C recommendation. Neither
implementation derives from any other codebase.

## Data

No sample terrain in this repository is derived from a restricted source. The
demonstration site is generated by the tool itself, in code, so it cannot go
stale against the readers.

⚠️ If you load imagery that is licensed for education and research only — for
example from Norge i bilder — the tool will let you preview a halftone of it
and will **refuse to export it**. That guard is deliberate. Please do not
route around it.
